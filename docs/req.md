# 需求说明（第二阶段：文档解析 + 录制优化）

## 阶段目标
- 进入第二阶段：文档解析与 Prompt 工程准备。
- 录制行为优化：对 input 采用防抖，对 click 采用节流，避免重复/噪声记录。

## 优化要求
- Input 防抖：默认 300ms，在同一输入框持续输入时只记录最后一次。
- Click 节流：默认 500ms，同一元素短时间连续点击仅记录一次。

## 约束
- 不引入新依赖，纯原生实现。
- 保持现有消息结构（action: RECORD_STEP, payload: {type/target/...}）。

## 验收标准
- 连续输入时不会生成大量重复记录。
- 连续点击同一按钮时不会快速刷屏。
